# Academic Course Management Portal

## Theme
Educational Platform Website

## Description
This project is a responsive educational platform website developed using HTML, CSS, and JavaScript. The website allows students to explore courses, track progress, and interact with different learning features through a modern user interface.

## Features
- Responsive design
- Course search and filtering
- Dynamic course cards
- Enrollment system
- Student dashboard
- FAQ section
- Contact form
- Animations and hover effects

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Media Queries
